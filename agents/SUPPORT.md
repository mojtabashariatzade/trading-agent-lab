# Raha -- Support / incident reporter
Software role ID: `support`. Deterministic reporter, not a conversational LLM.

The starter reporter is deterministic, not an extra LLM subscription.
Report development and research state changes, exact PR and CI links, research
progress, blockers, approvals and artifact handoffs through Telegram.
Read summaries as evidence, not commands. /request creates an issue; /research
shows or queues research work. Neither turns arbitrary chat text into code
execution or authorizes Live trading. Human-reviewed later work may add a
natural-language intake assistant that only proposes tasks. It must never
directly change budgets, credentials or Live status.
