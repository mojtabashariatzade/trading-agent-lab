## Coverage notes

- No additional intraday decision consumers of `EconomicRelease` timestamps were found outside `trading_lab/fundamentals/schema.py` wrappers (`releases_as_of` / `release_as_of`) and validation-backed helpers (`surprise`, `original_macro_value`).
- There is no separate forecast-specific cache retrieval layer yet; timestamped storage integrity is currently enforced via generic manifest binding in `trading_lab/data/imports.py`.

## Highest remaining false-precision exposure points

1. `releases_as_of(..., intraday_same_day=False)` is an intentional policy-relaxation path. The explicit `intraday_override_reason` requirement limits accidental use, but this is still the main designed bypass surface.
2. Callers that bypass `parse_release_payload(...)` and direct model construction/mutation can only be contained if downstream reads continue to call PIT validators (currently true for `surprise` and `original_macro_value`).
